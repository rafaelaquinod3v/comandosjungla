# 🌴 COMANDOS JUNGLA // jcore

The ultimate zero-dependency, standards-only PWA skeleton.  
Built for mission-critical systems. Governed by the **JWA3** specification.

---

## 🛡️ The 4 Rules (JWAV3)

### **Rule 1: Weight**
* Total transfer under **50 KB**.
* Insanely fast on 2G.

### **Rule 2: Privacy**
* Zero third-party requests.
* No external fonts or CDNs.

### **Rule 3: Native-First**
* Use direct browser APIs.
* No bundlers at runtime.

### **Rule 4: Accessibility**
* Strict ARIA roles required.
* WCAG 2.1 AA minimum.

---

## 🏗️ Architectural Layers

* **SOIL (Frontend)**
  * Semantic HTML5 and pure CSS.
  * Vanilla ES modules only.
* **SUBSTRATE (Lifecycle)**
  * Encrypted IndexedDB storage.
  * Ghost Engine Service Worker.
* **FORTRESS (Backend)**
  * Decoupled server-side infrastructure.
  * OPA/Rego policy enforcement.

---

## 🔒 Security Baseline (MCSwS)

* **Zero Trust**: No shared state in frontend.
* **Hardened CSP**: Strict Content Security Policy.
* **Kill-Switch**: 30-minute platform migration protocol.

---

1. **Clone** the repository.
2. **Serve** `index.html` locally.
